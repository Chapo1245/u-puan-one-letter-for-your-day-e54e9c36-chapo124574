One letter for your day: a Python program that writes exactly one letter — **O, for Overslept** — to `/output/entry.txt`. One picture says the whole day: eyes opening at noon, the alarm snoozed into silence, the morning already gone. Vivid, funny, and true. Deterministic: the same single byte on every run, standard library only.

## Run it

```sh
python3 main.py
```
